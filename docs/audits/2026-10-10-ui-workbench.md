# 图片优先工作台 UI 验证

## 变更

- 空参考输入首次绘制即折叠，有内容时自动展开。
- 提示词使用完整列宽，快捷引用说明进入帮助，桌面提交行容纳参数摘要与生成按钮。
- GPT 低频选项与动态模型高级参数默认折叠，折叠保留值，历史参数检查完整展示。
- 手机工具行和预览工具组更紧凑，固定生成栏保留；真实错误反馈继续显示。
- 历史详情与管理面板按需展开，管理入口在桌面持续可用。
- 无图卡区分加载、未生成、任务失败、加载失败和服务端确认的原图缺失；隐藏未知尺寸的技术值。
- 更新前端构建产物与缓存版本。

## 验证

- TypeScript 类型检查和前端静态产物生成通过。
- 135 项相关 Python unittest 通过（布局、参数锁定、参数覆盖层、模型参数和缩略图状态包装测试）。
- 33 项定向前端行为测试通过（历史操作、参数恢复和缩略图状态，其中缩略图测试也包含在上述包装测试中）。
- Playwright 隔离浏览器交互连续三轮通过：空输入校验、参考区展开、参数折叠保值、桌面与手机切换、深色主题、历史管理和详情开关、404 与服务器错误区分。每轮生成提交数均为零。
- 查看 1440×1000、390×844、2 倍截图，以及深色主题与历史详情。图片与供应商来自隔离测试服务；不代表真实供应商生成验收。
- 单轮独立存量视觉评审（不打分）指出首次进入参考区跳变；修正为初始折叠后重录并查看首帧和中间帧。
- 主操作校验、高级选项展开、首次进入各留三帧证据。环境无 ffmpeg，未输出视频。截图工具报告的无 src 图片对应隐藏的图库弹窗预览，页面可见图片未发现加载故障；错误状态验证中人为注入的 404/500 属于测试输入。

视觉证据和交互脚本留存在本地任务工作区，未包含用户历史库或凭据。本次为代码提交，不更新已安装程序或发布安装包。
